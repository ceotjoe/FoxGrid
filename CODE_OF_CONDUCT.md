# Verhaltenskodex / Code of conduct

FoxGrid ist ein Projekt von und für Funkamateure. Wir gehen respektvoll, sachlich und hilfsbereit miteinander um,
so wie man es auf einem guten Relais auch erwartet.

- Kritik an Code und Ideen ist willkommen, persönliche Angriffe sind es nicht.
- Keine Diskriminierung, Belästigung oder Beleidigung, weder in Issues, Pull Requests noch Discussions.
- Keine Veröffentlichung privater Daten anderer (Standorte, Rufzeichen-Zuordnungen, Kontaktdaten) ohne deren Zustimmung.
- FoxGrid dient dazu, Störungen zu finden. Aufrufe zu Belästigung, Störungen oder Selbstjustiz gegen
  identifizierte Personen sind hier nicht erwünscht; solche Beiträge werden entfernt.

Verstöße können privat an die Projektleitung gemeldet werden (GitHub: [@ceotjoe](https://github.com/ceotjoe)).
Die Projektleitung darf Beiträge entfernen und Personen von der Mitarbeit ausschließen.

*English:* Be respectful and constructive, no harassment or discrimination, do not publish other people's private
data, and do not use this project to organise harassment of identified individuals. Report problems privately to
the maintainer.
